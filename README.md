# Registration & Login System

A DBMS-based Registration and Login System developed as part of the Database Management Systems Lab (CSE 3522) Mid Exam Assignment-1.

## Features

- User Registration
- Email uniqueness validation
- Password hashing
- Phone number validation
- User Login
- Session Management
- Protected Dashboard
- Database-connected Dashboard
- Display logged-in user information
- Display registered users
- Logout functionality

## Database

The project uses a relational database with a `users` table containing:

- ID
- Name
- Email
- Password
- Phone
- Gender
